# Fahmi Daily v1.4.0

Pembaruan UI, status Google Calendar, dan pengingat 5 menit/kustom.
Data lokal fahmiDailyPWA.v1 dan koneksi Google/Cloudflare tetap kompatibel.
Unggah isi app/ ke lokasi index.html lama di GitHub Pages.
Lihat PANDUAN-UPDATE-v1.4.0.md untuk langkah lengkap.
Backend tetap v1.3.0 dan tidak perlu deploy ulang untuk update ini.

Perubahan: tombol tambah berlabel, judul jadwal dapat membungkus baris,
tanggal/status/pengingat di kartu, status Google dan akun/waktu terakhir,
konfigurasi teknis dalam Pengaturan lanjutan, koneksi langsung satu tombol,
pengingat kustom hingga 28 hari, serta bawaan khusus jadwal baru.
