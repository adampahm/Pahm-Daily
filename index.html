Agenda hari ini

Kegiatan

Google Calendar otomatis

Setelah terhubung, jadwal lokal dikirim ke kalender khusus Fahmi Daily. Tambah, edit, hapus dan pengulangan mengikuti aplikasi ini. Koneksi internet dan sesi Google aktif diperlukan.

Saat diaktifkan, judul, tanggal/jam, lokasi, catatan, kategori dan pengingat dikirim ke Google. Izin terbatas pada kalender yang dibuat aplikasi. Pilih akun Google yang sama di Kalender iPhone.

Setelah reload atau sesi kedaluwarsa, hubungkan kembali. Perubahan dari Kalender iPhone/Google tidak diimpor ke Fahmi Daily. Buat perubahan melalui aplikasi ini dan tetap lakukan backup JSON.

Isi Client ID aplikasi Web dari Google Cloud, bukan Client Secret. Panduan aktivasi

Pulihkan tautan kalender yang sudah dibuat

Gunakan bila pembuatan kalender sempat gagal dikonfirmasi atau pindah browser/perangkat. Ambil ID dari Google Calendar → Settings → kalender Fahmi Daily → Integrate calendar. Pulihkan backup jadwal lokal lebih dahulu.

Pengingat

Notifikasi

Reminder lokal hanya diperiksa saat aplikasi aktif. Saat aplikasi ditutup atau iPhone terkunci, reminder tidak dijamin. Gunakan Tambahkan ke Kalender untuk kegiatan penting.

Tambahkan ke Kalender

Buka menu ••• pada kegiatan, lalu pilih Tambahkan ke Kalender. File .ics berisi satu kejadian beserta alarm; perubahan jadwal tidak tersinkron otomatis.

Jika Kalender tidak muncul pada lembar Bagikan, simpan file dahulu. iOS tidak selalu dapat mengimpor .ics langsung dari Files/Safari. Apple mendukung impor lampiran .ics melalui Mail; pilihan ini memerlukan Anda mengirim file sendiri dan melibatkan layanan email. Untuk tetap sepenuhnya lokal, masukkan event secara manual di Kalender jika impor tidak tersedia. Aplikasi tidak mengirim email atau mengupload file.

Periksa waktu, kalender tujuan, dan alarm sebelum menyimpan. Jika kalender tujuan memakai iCloud/akun lain, event mengikuti sinkronisasi akun itu; pilih kalender lokal bila tersedia.

Aplikasi & penyimpanan

Data jadwal disimpan lokal; saat integrasi Google diaktifkan, salinannya dikirim ke Google Calendar. Buat backup berkala; menghapus data situs/aplikasi dapat menghapus jadwal. Saat berpindah URL atau perangkat, pulihkan backup JSON.

Instal di iPhone

  1. Buka alamat PWA ini di Safari.
  2. Tekan tombol Bagikan.
  3. Pilih Tambahkan ke Layar Utama.
  4. Tekan Add / Tambah.
  5. Buka Fahmi Daily dari Home Screen.

Cara Pasang di iPhone

  1. Buka URL Fahmi Daily menggunakan Safari.
  2. Tekan Share / Bagikan.
  3. Pilih Add to Home Screen / Tambahkan ke Layar Utama. Jika tersembunyi, lihat daftar aksi lainnya.
  4. Tekan Add / Tambah. Jika ada pilihan Buka sebagai App, aktifkan.
  5. Buka Fahmi Daily dari Home Screen.

Tunggu status offline siap sebelum mencoba mode pesawat.
