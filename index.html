Tambahkan ke Kalender

Buka menu ••• pada kegiatan, lalu pilih Tambahkan ke Kalender. File .ics berisi satu kejadian beserta alarm; perubahan jadwal tidak tersinkron otomatis.

Jika Kalender tidak muncul pada lembar Bagikan, simpan file dahulu. iOS tidak selalu dapat mengimpor .ics langsung dari Files/Safari. Apple mendukung impor lampiran .ics melalui Mail; pilihan ini memerlukan Anda mengirim file sendiri dan melibatkan layanan email. Untuk tetap sepenuhnya lokal, masukkan event secara manual di Kalender jika impor tidak tersedia. Aplikasi tidak mengirim email atau mengupload file.

Periksa waktu, kalender tujuan, dan alarm sebelum menyimpan. Jika kalender tujuan memakai iCloud/akun lain, event mengikuti sinkronisasi akun itu; pilih kalender lokal bila tersedia.

○ Belum terhubung

Jadwal belum lengkap di iPhone?

Jika semua kegiatan muncul di Google Calendar, periksa kalender yang dipilih di iPhone.

  1. Pengaturan iPhone → App → Kalender → Akun Kalender: pilih akun Google yang sama dan aktifkan Kalender. Pada iOS lama, buka Pengaturan → Kalender → Akun.
  2. Buka Kalender iPhone → Kalender di bagian bawah. Centang Fahmi Daily di bawah akun tersebut, lalu Selesai.
  3. Periksa tanggal kegiatan. Jika ada beberapa Fahmi Daily, cocokkan ID kalender tujuan di Lihat Detail dengan Google Calendar → Setelan → Integrasikan kalender.

Menu Ekspor kegiatan (.ics) hanya menyalin satu kejadian. Untuk semua kegiatan dan pembaruan otomatis, gunakan koneksi Google.

Pulihkan tautan kalender yang sudah dibuat

Gunakan bila pembuatan kalender sempat gagal dikonfirmasi atau pindah browser/perangkat. Ambil ID dari Google Calendar → Settings → kalender Fahmi Daily → Integrate calendar. Pulihkan backup jadwal lokal lebih dahulu.
